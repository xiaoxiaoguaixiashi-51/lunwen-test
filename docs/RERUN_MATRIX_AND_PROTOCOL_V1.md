## 冻结数值及含义

沿用已配置deepseek-flash、temperature=0.2、thinking=disabled、max_tokens=8192、SDK重试0、单请求超时120秒。保留返回模型标识；服务别名不保证权重不可变。同一变体/重复的初始、种子修复与反馈共用新账本；变体及重复之间账本分开。

LLM每目标上限12次、240000输入+输出token、单次输入含256封装预留不超过12000、输出不超过8192；本地tokenizer哈希固定。未知usage或实际超限阻断后续请求，先调查不重发。初始最多3次编译（至多2次模型修复）；种子失败最多1次修复；反馈最多3轮，每轮最多1次修复，无缺口提前结束。修复后仅工具通过的测试仍待语义复核，不能自动纳入主覆盖。

EvoSuite正式搜索每类120秒，外层超时300秒；评估阶段各工具超时120秒，JUnit/JaCoCo/main类树及认可口径共用。RAG仍是单次生成，不为消耗相同额度增加KCF修复。**一致资源上限不等于实际计算量相等，更不等于EvoSuite与LLM等预算。** 报告全部实际成本、覆盖—成本关系与预算偏离；编辑对严格等预算的顾虑没有仅靠这些上限就完全解决。

计划5次配对完整重复r01—r05，EvoSuite种子31001—31005；LLM未声明支持可固定随机种子。重复数是预先选择的波动报告规模，不是功效充分保证；变更须先出新版本再执行正式运行，不能见结果追加到显著。按项目与共享类说明相关性，报告每次配对差值及不确定性，不把41目标当41独立生成任务。正式调度应预先保存运行顺序并平衡方法/项目顺序，当前小规模固定顺序不充当该设计。

从已用于开发的六目标清单中预先选CSV printComment与JDom construct，覆盖先前断言失败与可修复案例。两个目标属于开发样本，不是独立验证；选择在本次API返回前冻结。Full/A1/A2/A3/RAG各一次；KCF只做1轮覆盖反馈，EvoSuite每类30秒、种子31000。这是比正式规格短的工作流检查，不混入正式5次结果。

最多66次真实供应商尝试，按每次上限计算最多1332672输入+输出token；该数字是预设最坏上界，不是费用估计或实际消耗。供应商串行、零自动重试；新目录、新账本、新生成产物，不以旧通过测试作种子。各阶段保存实际开关、API/阶段/执行成本、来源哈希及失败类别。首次出现供应商/未知费用错误或非测试类基础设施错误就停止，不为补齐表格自动追加请求。

编译/断言失败可以作为正常试验结果，不能当环境问题删掉；具体错误须核对日志。真正环境问题修复后复用已保存生成源码，优先零追加API重评，保留原失败记录。任何续跑/追加范围和已用额度须单独记录，不能换目录绕开66次总界。
